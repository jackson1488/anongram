# AnonGram UI/UX Интерактивные Макеты (Mockups)

В этой папке собраны все интерактивные HTML-макеты интерфейса AnonGram, которые можно открывать в любом современном веб-браузере:

1. **`whatsapp_call_ui_mockup.html` (также доступен в корне `frontend/`)**:
   - Макет звонков в стиле WhatsApp.
   - Быстрый ответ на входящий вызов прямо из Heads-Up уведомления (в шторке поверх других программ).
   - Полноэкранный защищенный вызов с SAS-эмодзи верификацией (`🦊 🛡️ 🚀 🌊`).
   - Режим Picture-in-Picture (PiP): перетаскиваемое плавающее окно поверх экрана с кнопками микрофона, видео и сброса.
   - Динамический апгрейд 1-на-1 звонка в группу (+Группа).

2. **`android_notification_mockup.html`**:
   - Интерактивный макет 5-уровневой системы адаптивных уведомлений Android.
   - Разворачивание/сворачивание списков чатов по отдельности и глобально.

3. **`anongram_mobile_prototype.html`**:
   - Полный мобильный интерактивный прототип интерфейса клиента AnonGram.
   - Экраны чатов, профиля, настроек приватности и биометрии.

4. **`anongram_architecture_and_ui.html`**:
   - Интерактивная визуализация модульной архитектуры и UI компонентов приложения.
