🛡️ AnonGram OTP Level 3 + Hybrid PQ

План модульной архитектуры клиента (Flutter / Clean Architecture + Rust Core FFI) и интерактивный прототип UI.

🎨 Presentation Layer (Flutter)

BLoC / State
  • ChatBloc & SecurityBloc Управление событиями UI, индикация уровня щита (Gold/Blue), реактивный поток сообщений.
  • ChatRoomScreen & OtpVaultSheet Интерфейс чата с индикатором расхода пада в реальном времени и кнопкой сожжения.
  • DynamicThemeWidget Адаптивная отрисовка криптографического статуса (отсутствие разглашения метаданных).

🧠 Domain Layer (Чистая логика)

SOLID / Pure Dart
  • Entities & Value Objects PassportEntity, PadManifestEntity, ShieldLevel. Не зависят от UI и БД.
  • Use Cases (Интеракторы) SendOtpMessageUseCase, ImportPhysicalPadUseCase, BurnIdentityUseCase.
  • Repositories Interfaces IPadRepository, IPassportRepository, IRelayNetworkRepository.

⚙️ Data & Rust Core FFI

Zeroize / C-ABI
  • anongram_core (Rust Crate) ML-KEM-1024, ML-DSA-87, X25519, Poly1305, Двусторонний OTP со строгим затиранием на носителе.
  • NativeBridgeAdapter Dart FFI биндинги к скомпилированной динамической библиотеке libanongram_core.so.
  • DualContainerStorage Основной зашифрованный контейнер и Decoy (при Duress-пароле стирает мастер-ключи).
