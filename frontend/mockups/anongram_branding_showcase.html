📱 2. Сплэш-экран (Заставка при запуске приложения)

Launch Screen Mockup
✨ Мгновенный холодный старт

Элегантная минималистичная заставка

При запуске AnonGram на экране смартфона появляется глубокий обсидиановый фон с тонкой голографической сеткой. По центру мягко пульсирует неоновый символ, под которым отображается название ANONGRAM и статус: «Zero-Knowledge Cryptographic Network».

✓ Без мерцания и белых вспышек в темноте (True AMOLED Black).
✓ Совместимо с Android 12+ SplashScreen API и iOS LaunchScreen.storyboard.
✓ Пока горит заставка, Rust Core в фоне расшифровывает SQLite базу за 0.05 сек.

Notification Tray Icon
