# Архитектура и Документация Ядра: Модуль `crypto`

## 1. Для чего и зачем нужен этот модуль?
Модуль `crypto` — это фундамент безопасности мессенджера AnonGram. Его единственная задача: **математическая стойкость шифрования против квантовых компьютеров и традиционных суперкомпьютеров**.

Обычные мессенджеры (Signal, Telegram, WhatsApp) используют классическую криптографию на эллиптических кривых (Curve25519) и RSA. Проблема в том, что спецслужбы уже сегодня перехватывают и сохраняют зашифрованный трафик («Harvest Now, Decrypt Later» — *Собери сейчас, расшифруй потом*). Когда через несколько лет появится квантовый компьютер достаточной мощности с алгоритмом Шора, все старые переписки будут мгновенно расшифрованы.

Модуль `crypto` устраняет эту угрозу, объединяя классическую криптографию и постквантовую математику решёток NIST.

---

## 2. Что делает модуль (Анатомия и Алгоритмы)?

1. **Аутентифицированное шифрование данных (`aead.rs`)**:
   - **Алгоритм**: XChaCha20-Poly1305.
   - **Размер ключа**: 256 бит (32 байта).
   - **Случайный Nonce**: 192 бита (24 байта). За счёт огромного 192-битного пространства вероятность коллизии случайного nonce равна нулю (даже при триллионах сообщений повтор исключен).
   - **Аутентификация Poly1305**: Каждый пакет снабжается 16-байтным имитовставочным тегом (MAC) и связывается с AAD (Associated Authenticated Data). Подделать или изменить хотя бы один бит невозможно.

2. **Гибридный постквантовый KEM (`kem.rs` - Key Encapsulation Mechanism)**:
   - Объединяет **ML-KEM-1024** (стандарт NIST FIPS 203, криптография на модульных решётках Crystals-Kyber) и классический **X25519**.
   - **Формула синтеза сессионного секрета**:
     $$SS = \text{HKDF-SHA256}(SS_{X25519} \parallel SS_{ML-KEM} \parallel CT_{X25519} \parallel CT_{ML-KEM} \parallel PK_{Recipient})$$
   - Принцип «Dual Hardness»: если когда-нибудь будет взломан X25519 (квантовым компьютером) — защита останется непоколебимой благодаря ML-KEM. Если в новой постквантовой математике обнаружат теоретическую уязвимость — защита удержится за счёт X25519.

3. **Гибридные цифровые подписи (`sign.rs`)**:
   - Объединяет классический **Ed25519** и постквантовый **ML-DSA-87** (Crystals-Dilithium, NIST FIPS 204).
   - Подпись валидна **только тогда, когда обе математические подписи сошлись на 100%**.

---

## 3. Изоляция и Безопасность
* В модуле `crypto` **нет никаких сетевых зависимостей** (нет сокетов, нет сетевых протоколов).
* Все секретные ключи реализуют трейт `Zeroize`: при выходе переменной из области видимости память в RAM затирается нулями аппаратной инструкцией процессора.
