# Спецификация Системы Уведомлений AnonGram: Адаптивный 5-списочный Multi-Inbox

## 1. Концепция и UX-Архитектура
В шторке Android создается **ровно ОДНО системное уведомление**, объединяющее всю активность мессенджера без спама на экране:

1. **Лимит отображения (5 Списков)**:
   - Внутри одного уведомления отображается **максимум 5 активных чатов/групп** (мини-списков).
   - Если активных диалогов больше 5 — в шапке показывается бейдж **`+1`**, **`+2`**, указывающий на скрытые диалоги в приложении.
2. **Превью последнего сообщения**:
   - В свернутом состоянии в каждой из 5 строк виден автор и текст последнего входящего сообщения.
3. **Общая кнопка справа сверху «Развернуть побольше / Свернуть компактно»**:
   - Масштабирует всё уведомление целиком, увеличивая паддинги и читаемость.
4. **Индивидуальное раскрытие каждого из 5 списков**:
   - У каждого из 5 чатов есть своя независимая стрелочка/кнопка раскрытия.
   - При нажатии раскрывается полная переписка конкретного чата, превью зашифрованных фото (без EXIF) и кнопки действий.
5. **Интерактивные действия без открытия приложения**:
   - Кнопка «Ответить» (Inline Direct Reply) с отправкой зашифрованного ответа прямо из шторки.
   - Кнопка «Прочитано».

## 2. Архитектура доставки: 4 Уровня доставки полезной нагрузки

| Уровень | Тип контента | Маршрут доставки | Поведение ядра и шторки |
| :--- | :--- | :--- | :--- |
| **Уровень 1** | Короткий текст (до ~1300 симв.) | Напрямую в FCM Data Push (до 4 КБ) | Сокет **НЕ ВКЛЮЧАЕТСЯ**. Ядро расшифровывает текст в RAM за 1 мс и сразу обновляет шторку. Ноль расхода батареи. |
| **Уровень 2** | Фото / Гифка / Медиа | Зашифрованное превью в Push (~150 байт) + `MediaId` | Шторка сразу показывает размытое превью/миниатюру. Фоновый воркер ядра тихо подтягивает оригинал через сокет сервера. |
| **Уровень 3** | Длинный текст (> 1300 симв.) | Первые 300 симв. в Push + `MessageId` | Шторка сразу показывает начало текста, а полный объем фоном скачивается из очереди сервера. |
| **Уровень 4** | Обрыв / Блокировка сокета | Полный Push Fallback | Если цензор заблокировал TCP/UDP сокеты, экстренные команды и сообщения передаются пакетами по 4 КБ через FCM. |

## 3. Структура данных ядра (Rust `crates/push` & `crates/control`)

```rust
pub struct MultiInboxNotificationState {
    pub total_unread_count: u32,
    pub total_conversations_count: u32,
    pub displayed_chats: Vec<ChatNotificationSummary>, // Максимум 5 элементов
    pub overflow_count: u32,                           // Если > 5, например +1, +2
}

pub struct ChatNotificationSummary {
    pub chat_id: [u8; 32],
    pub title: String,
    pub is_group: bool,
    pub unread_count: u32,
    pub last_message_preview: String,
    pub full_messages: Vec<NotificationMessageItem>,
    pub media_thumbnail: Option<Vec<u8>>,
}

pub struct NotificationMessageItem {
    pub sender_id: [u8; 32],
    pub sender_name: String,
    pub text: String,
    pub timestamp: u64,
}
```
